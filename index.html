Sistema de Gestión de Tareas con API y Base de Datos

PFO2 · Programación sobre Redes · IFTS 29

Presentación del proyecto

El sistema permite registrar usuarios, iniciar sesión y acceder a una bienvenida mediante una API desarrollada con Flask. Utiliza SQLite para almacenar usuarios y hashes para proteger las contraseñas.

Incluye un cliente de consola con un menú para interactuar con la API.
